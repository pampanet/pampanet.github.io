This is my first blog post written from my own blog editor using Markdown.

The purpose of this page is to showcase my programming and software design skills by not only making things from scratch (like the blog DB and animations) but also reusing existing software in the form of Flutter plugins.

  • Flutter Web

The blog has a simple breadcrumb plugin that shows:

<home>/<search criteria>/<entry title>
